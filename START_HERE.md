# Start here on your laptop

1. Open this folder in Terminal / Command Prompt.
2. Install once:

```bash
pip install -r requirements.txt
```

3. Start the menu:

```bash
python scripts/start.py
```

Choose:
- 1 = tests
- 2 = paper trading (no real money)
- 3 = research backtest
- 4 = walk-forward
- 5 = Binance testnet setup
- 6 = Binance testnet run

Live trading is locked.
