# Binance — Testnet only

FATE QUANT does not use your real Binance account yet.

1. Open https://testnet.binance.vision
2. Log in / create a testnet account
3. Create Spot API key + secret
4. On your computer, in fate_quant run:

```bash
python scripts/setup_binance_testnet.py
```

5. Then:

```bash
python scripts/run_testnet.py
```

Live/mainnet trading is locked.
Do not paste keys in chat.
