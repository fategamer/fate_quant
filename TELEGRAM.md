# Telegram setup — short

This is done on a **computer**, not inside the Telegram app.

1. Open the `fate_quant` folder on your computer.
2. Run:

```bash
python scripts/setup_telegram.py
```

3. When it asks, paste:
   - bot token from @BotFather
   - chat id from @userinfobot
4. Look at Telegram. You should get a test message from Fate Quant Bot.

If you are only on iPhone, you cannot complete this step until you use a computer.
